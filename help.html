0. 全体の流れ

トップページ（入口）

アドレスをそのまま開く（末尾に何も付けない）と トップページ（index.html）が出ます。入口は 2 つだけです。

  • ＋ 大会を新規作成 … テンプレート・コピー・完全新規から選んで大会を作ります（§1「大会を作る」）。
  • ▶ 大会一覧 … いまある大会の一覧です。行を押すと、その大会の運営画面が直接開きます。行の右の ⋯ から コピーして作成・得点を消して複製・ファイルに保存・アーカイブ・削除ができます（運営画面に大会一覧はありません）。

一覧は 更新の新しい順に並び（状態が変わっても並びは変わりません）、5 件まで出ます。残りは すべて見る で開きます。アーカイブ済みの大会は下の ▸ アーカイブ（n 件） に畳まれます。システムテスト用 のテンプレートで作った大会は既定で隠れていて、テストも表示 にチェックを入れると テスト の印付きで出ます。

入口の下の小さなリンクから 採点画面・順位表示・ヘルプ へ行けます。コート端末の方はここから採点画面へ入ってください。アプリの説明と 7 段階の流れは ▸ このアプリについて に畳まれています。

右上の 🖥 / 📱 は、運営画面の行き先を PC 用（desk.html）とスマホ用（admin.html）で切り替えるボタンです。押した端末に控えられるので、次に開いたときも同じほうが出ます。

以前のアドレス（採点画面が index.html だった頃のブックマーク）を開くと、自動で scoring.html に移ります。コートのタブレットのブックマークは貼り替えなくて構いません。

大会は、大会を作るところから発表までを一本の流れで進めます。

一巡目＝全員が1回ずつ斬る回です。二巡目＝同じ選手がもう1回斬る回です。得点は一巡目と二巡目を合わせた合計で競います。

大会には 状態 があります。運営者が 次へ進む のボタンで1段ずつ進め、自動では変わりません。

  1. 準備中 — 技得点表・選手を自由に入れられます。採点はまだできません。
  2. 一巡目 進行中 — コートの端末で一巡目を採点します。
  3. 二巡目準備（形の登録） — 一巡目を終了すると、二巡目の行が自動でできます（形は申請された二巡目の形。申請の無い選手は一巡目と同じ）。当日の変更があれば形を直し、確かめ終えたら二巡目を開始します。
  4. 二巡目 進行中 — コートの端末で二巡目を採点します。全員が斬り終わったら 二巡目を終了 ▶ を押します。
  5. 二巡目終了 — 順位を確かめます。試合進行に3部門の上位3名の要約が出ます。直したいことがあれば1つ前に戻せます。
  6. 最終結果 — 得点・選手・技を編集できなくなります。試合進行に表彰の区画（上位3名と、発表モード・共有リンク・成績表のボタン）が出ます。発表・共有・ファイル保存はできます。
  7. アーカイブ — 見るだけ。大会一覧の「アーカイブ」欄に移り、採点画面の選択肢から消えます。
二巡目の試技順は、コートごと・部（男子・女子）ごとに一巡目の得点が低い順です。最後のほうに斬らせたい選手（ベスト4 に入りそうな人など）がいれば、運営者が採点画面の選手一覧か選手登録でドラッグして入れ替えます（システムが選んで並べ替えることはありません）。
二巡目を行わない大会は、二巡目準備（形の登録） のときに 二巡目を行わず最終結果へ（PC 用。試合進行 の工程表の下）／二巡目なしで終了（スマホ用。⋯ メニュー）で 最終結果 へ進めます。どの状態からも 戻す（PC 用は 試合進行 の工程表の下、スマホ用は ⋯ メニュー）で1つ前に戻せます。

PC 用の運営画面では、大会名の下の状態バーに 準備中 → 一巡目 → 形登録 → 二巡目 → 最終結果 の5段で出ます（いまの段が金色）。上の7つの状態との対応は次のとおりで、進行中・二巡目終了・アーカイブは段の中に小さく添えます（例: 二巡目 二巡目終了、最終結果 アーカイブ）。右に 確定 5 / 8 のような件数が出ます。

  • 一巡目 … 一巡目 進行中
  • 形登録 … 二巡目準備（形の登録）
  • 二巡目 … 二巡目 進行中・二巡目終了
  • 最終結果 … 最終結果・アーカイブ
状態バーは表示だけです。状態を進める・戻すボタンは工程表の下にだけあります。工程表は状態バーより細かく、① 一巡目 → ② 二巡目の形登録 → ③ 二巡目 → ④ 結果・表彰 の4段です（③ が二巡目 進行中、④ が二巡目終了・最終結果・アーカイブです）。工程表は 試合進行 の区画の先頭と 選手登録 の区画の先頭、二巡目準備のときは 二巡目の形登録 の区画の先頭にも出ます（§2「当日の流れ」）。選手を登録し終えたら、その場で 試合開始 ▶ を押せます。

大会のデータはサーバーに1つだけあります。運営者の PC もスマホも、各コートのタブレットも、同じ大会を読み書きします。

図の各段が、上に並べた 7 つの状態です。段と段の間は、運営画面の 次へ進む のボタン（試合開始 ▶ 一巡目を終了 ▶ …。PC 用は 試合進行 の工程表の下）で進みます。運営画面で状態を進めないと、コートの端末は採点できません。

1. 大会の作成

大会前の準備

前日までに 技得点表（techniques.html。トップの 技得点表 からも開けます）を開いて、技名と配点が今年のものになっているか確かめてください。開いた直後は閲覧モード（文字だけの表）です。直すときは ✎ 編集する を押します。

配点は大会ごとです。画面の上の 表示する対象 で、雛形（新規大会の初期値） かどの大会かを選びます（ハッシュ無しで開くと、進行中の大会があればそれが選ばれます）。雛形を直しても、すでにある大会の配点は変わりません。大会を作る前に雛形を直しておくと、その後に作る大会にそのまま入ります。

大会が始まってから配点を変えると、すでに採点した選手の保存済みの得点は変わらないまま、新しい配点との食い違いが残ります。食い違った選手は、採点画面で開くと 技得点表の変更で点が変わります（保存 16 → 再計算 21） と出るので、計算し直して保存 を押して直します。配点の確認は必ず大会の前に済ませてください。

大会を作る

いちばん簡単なのはトップページからです。トップの ＋ 大会を新規作成 を押すと、4 つの作り方から選べます。

  • 前回の大会をコピー … 直近に触った大会（テスト大会とアーカイブ済みを除く）をそのままコピーします。毎回の大会はこれがいちばん速いです。
  • テンプレートから … 下の 3 種類から選びます。
  • 大会一覧からコピー … 元にする大会を選んでコピーします（アーカイブ済みも選べます）。
  • 完全新規 … 名前・日付・会場だけの空の大会です。技と配点は雛形から入ります。

どれを選んでも、次の画面で 大会名・日付（今日が入っています）・会場 を入れて 作成 を押します。作ったあとは、その大会の 選手登録 が開きます。

テンプレート 3 種

  • 稽古用 … 技と配点は雛形のまま。コートは 稽古 の 1 つ。選手は 0 名。道場の稽古でその場の何人かを採点するとき。
  • 大会用 … 技と配点は雛形のまま。コートは A・B。ゼッケン番号を必須にする が入った状態。選手は 0 名。本番の大会を一から作るとき。
  • システムテスト用 … 大会用 に加えて、ダミーの選手 20 名（男子01〜10・女子01〜10、ゼッケン 1〜20、A と B に交互、技も入っている）。初めての人が練習する・新しい端末で通しの確認をするとき。
システムテスト用 で作った大会には テスト の印が付き、トップの 大会一覧 では既定で隠れます（テストも表示 で出ます）。採点画面の選択肢には、いつでも出ます。練習が終わったら消してください。

運営画面には PC 用（desk.html）と スマホ用（admin.html）があります。中身は同じ大会で、ヘッダーの 🖥 / 📱 でいつでも行き来できます。当日の受付や名簿の打ち込みは PC 用が向いています。

大会を作るのはトップの ＋ 大会を新規作成 だけです（前回の大会をコピー／テンプレート／大会一覧からコピー／完全新規）。作ると、その大会の運営画面の 選手登録 が開きます。運営画面に「新規作成」はありません。大会を切り替えるときは、PC 用は左の区画の ← 大会一覧、スマホ用は ⋯ → 🏠 トップ でトップの大会一覧へ戻って選びます。

このマニュアルの画面写真はスマホ用のものです。PC 用は同じ内容を広い画面に並べたもので、ボタンの名前もほぼ同じです。

去年の大会をコピーして作る

トップの 大会一覧 で、元にする大会の行の ⋯ → 📄 コピーして作成 を押します（トップの ＋ 大会を新規作成 → 大会一覧からコピー と同じ画面が、その大会を選んだ状態で開きます）。

  • 大会名（「元の名前（コピー）」が入っています）・日付（今日）・会場 を直します。
  • 選手も複製する（得点は消す） にチェックを入れると、元の大会の一巡目の選手だけが、名前・コート・性別・新人・技（二巡目の形の申請があればそれも）をそのままに、得点 0 で入ります。二巡目の行は複製しません。
  • 技と配点は必ず複製されます。共有リンクと配信用ボードのアドレスは引き継ぎません。

できた大会は 準備中 です。アーカイブ済みの大会からもコピーできます。

入力を省くなら、行の ⋯ → 📑 得点を消して複製 です。確認のあと、選手（一巡目の行）と技・配点をそのまま写して得点だけ消した大会が「元の名前（コピー）」・今日の日付で作られ、その選手登録が開きます。名前と日付は基本情報で直せます。

基本情報（コート・必須の設定）

PC 用の運営画面で大会を開き、左の 基本情報 を選ぶと、大会名・日付・会場のほかに コート一覧 を編集できます。

  • ＋ コートを足す でコート名（A など）を入れます。選手が 1 人もいなくても、そのコートが選手登録のコート候補と 試合進行 のカードに出ます。
  • 足したコートは × で外せます。灰色のコート（「A（選手あり）」）は選手のコート指定から決まったもので、外せません。外すときは 選手 の区画でその選手のコートを変えます。
  • コート名の決まり: 空・-・未分類 は使えません。32 文字まで、同じ名前は 1 つだけ、20 コートまでです。
  • 足した・外したあとは 保存 を押してください（上の 保存 でも同じように保存されます）。

同じ画面の ゼッケン番号を必須にする / 級位・段位を必須にする は、一巡目にその項目が空の選手がいる間だけ 試合開始 ▶ で止めるための設定です（§2 の「当日の流れ」）。登録そのものは空のままできます。

終わった大会を片づける（アーカイブ）

最終結果 まで進んだ大会は アーカイブ にできます。試合進行 の工程表の下の アーカイブ ▶、またはトップの大会一覧の行の ⋯ → 📥 アーカイブ です。

  • トップの大会一覧では、下の ▸ アーカイブ（n 件） に畳まれます。当日の大会と混ざりません。
  • 採点画面の大会の選択肢から消えます。押し間違えて去年の大会に採点してしまう事故を防ぐためです。
  • 見るだけはできます。共有リンクと発表モードもそのまま開けます。
  • 戻すときは 試合進行 の ◀ 最終結果 に戻す です。

別のサーバーや PC から取り込む

ほかのサーバーで作った大会を、そのまま持ってこられます。大会情報・技の配点・選手（採点済みの得点も）・採点履歴が一緒に入ります。

  1. 持ち出す側で、トップの大会一覧の行の ⋯ → 💾 ファイルに保存（または PC 運営の 基本情報 の 💾 ファイルに保存、スマホ運営の ⋯ → 💾 大会をファイルに保存）を押す。tameshigiri_日付_大会名.json が保存されます。
  2. 取り込む側で、トップの 📂 ファイルから取り込む を押し、そのファイルを選ぶ。
  3. 大会を取り込みました（n 名） と出て、選手登録タブが開きます。
取り込みはいつも新しい大会として追加されます。同じ名前の大会があっても上書きされません。同じ名前と日付の大会が既にあるときは 同じ名前と日付の大会が既にあります。別の大会として追加しますか？ と確認が出ます。共有リンクと配信用ボードのアドレスは持ち込まれないので、取り込んだ側で作り直してください（§4）。選手だけを足す CSV（選手登録の 📄 選手を CSV から取り込む）とは別の機能です。大会ファイル（.json）は選手登録では読めません。

選手を登録する

タブで 選手登録 を選びます。登録のしかたは3通りあります。

（a）1人ずつ登録する

右下の赤い ＋ を押すと 選手を追加 のシートが開きます。

  • 名前 を入れる。
  • コート を選ぶ（A B、＋ で増やせます）。
  • 性別 を選ぶ（男子 女子）。
  • 新人なら 新人 にチェックを入れる。
  • ゼッケン番号 を入れる（1〜9999 の整数。空でも登録できます）。同じ大会の中で同じ番号は使えません。すでに使われている番号を入れると ゼッケン番号 12 は「山田 太郎」が使っています と出ます。
  • 級位・段位 を入れる（無級 十級〜一級 初段〜十段 の候補から選べます。錬士六段 のように自由にも書けます。20 文字まで）。
  • 真剣を借りる選手は 真剣レンタル にチェックを入れる。チェックすると、技の候補が抜刀後の形だけになります（下の「技の選び方」）。
  • 技を ① ② ③ の枠ごとにタップして選ぶ。
  • 二巡目で形を変える選手だけ、二巡目の技（空なら一巡目と同じ形） の ①②③ も選びます（大会の前に申請を受けているとき）。空のままなら、一巡目と同じ形で二巡目を行います。申請が空のまま最初の枠を押すと、一巡目の技が下書きとして入ってから開くので、変える枠だけ選び直せば済みます。一巡目と同じにする で空に戻せます。
  • 保存して次を追加 で続けて登録、保存して閉じる で終わります。
ゼッケン番号と級位・段位は、空のままでも登録できます。PC 用の運営画面の 基本情報 で ゼッケン番号を必須にする / 級位・段位を必須にする にチェックを入れると、一巡目にその項目が空の選手がいる間だけ 試合開始 ▶ で止まります（§2 の「当日の流れ」）。登録の途中で止められることはありません。

（b）複数人をまとめて登録する

右上の ⋯ → 👥 複数人をまとめて登録 を押します。

  • コート・性別・新人 はその場の全員に共通で付きます。
  • 名前（1行に1人） の欄に名簿を貼り付けます。下に人数が出ます。
  • 登録 を押すと A コート 男子 4 人を登録します。よろしいですか？ と確認が出ます。OK でまとめて入ります。
技はこの方法では入りません。あとから選手登録タブで1人ずつ入れてください。コートや性別が違う人は、条件ごとに分けて登録します。

（c）CSV で読み込む

右上の ⋯ → 📄 選手を CSV から取り込む を押し、ファイルを選びます。

いちばん簡単な形は次の7列です。1行目は見出し行で、2列目が「コート」であれば、この形として読みます。

名前 , コート , 性別 , 技① , 技② , 技③ , 新人
  • 性別は 女 女子 ○ F f のいずれかで女子、ほかは男子になります。
  • 新人は ○ 1 はい 新人 のいずれかで新人になります。
  • 順番はサーバーが自動で採番します。CSV に書く必要はありません。
  • コート名は32文字までです。- は使えません。未分類 も使えません。

右に ゼッケン 級位段位 レンタル、さらに 二巡目技① 二巡目技② 二巡目技③ の列を足せます（合わせて 13 列。PC 用の貼り付けと同じ並びです）。二巡目の技は、二巡目で形を変える選手だけ書きます（空なら一巡目と同じ形。書くときは 3 つとも）。二巡目技1 の書き方の見出しも読めます。

運営画面の結果確認の CSV エクスポート が出す形（選手名 順番 … の 9 列・12 列・15 列・18 列、決戦（今は使いません。列は互換のため残し、書き出しは空、取り込みでは読み飛ばします） 一巡目の行 が付いた 20 列、そして最後に 二巡目 技 1 二巡目 技 2 二巡目 技 3 が付いた 23 列）もそのまま読み込めます。以前の 20 列のファイルも読めますが、その場合は二巡目の形の申請は空になります（二巡目の行の形は 3〜5 列目の技で往復します）。この形では順番は CSV の値をそのまま使います。1 行目の見出しを厳密に照合します。読み込める形でないと CSV の 1 行目（見出し）が、読み込める形式と合っていません。 と出て、何も読み込みません。

文字コードは UTF-8 を先に試し、化けていれば Shift_JIS で読み直します。どちらでも読めないときは CSV の文字が化けていて読み取れませんでした。 と出ます。Excel なら CSV UTF-8（コンマ区切り） で保存し直してください。

すでに選手がいる大会に読み込むと、取り込む直前にサーバーの選手数を読み直してから、読み込み方を選ぶ画面が出ます（画面の表示が古くても、いま何名いるかで聞きます）。

  • 追記する — 既存の選手を残して、CSV の選手を足します。同じ順番の選手がいると重複します。
  • 置き換える（既存 n 名を消す） — 既存の選手を全部消して、CSV の内容だけにします。採点結果も消えます。押し間違えないよう、危ない方は赤いボタンで、何が消えるかをボタンに書いてあります（OK で進む形にはなっていません）。

コートの端末に運営のパスワードを配らなくても、そのコートの採点だけができる端末を QR で登録できます（PC 用の運営画面から行います）。登録した端末は、その大会・そのコートの採点画面だけが開きます。

  2. ラベル（例: A コート タブレット）・期限・端末の数を決めて 発行する。期限は大会の日の終わり（日本時間 23:59）が標準です。端末の数は、この QR で登録できる台数の上限です（標準は 2 台、最大 5 台）。
  3. 画面に QR が出ます。会場で、タブレットのカメラに読み取らせます。開いた画面で この端末を登録する を押すと、登録が済んで採点画面に移ります。
  4. 採点画面をSafari（ブラウザ）でブックマークしておくと、次からそこから開けます。QR を読み取り直す必要はありません。
「ホーム画面に追加」は採点画面ではなく /join を。iPad・iPhone では、ホーム画面に追加したアプリはブラウザと登録（Cookie）が別になることがあり、採点画面を追加すると、開いたときに運営の ID・パスワードを聞かれます。ホーム画面に置きたいときは /join のページを追加し、開いたら運営からもらった URL を貼り付けて登録してください（登録すると採点画面に移ります）。ID・パスワードの画面が出てしまったら、閉じると出る案内から /join に進めます。
QR は採点ができる鍵です。写真に撮って送らない・他の人に見せないでください。この QR の画面を閉じると二度と表示できません（必要なら新しく発行します）。端末が登録できる数に達したあとは、同じ QR を読み取っても断られます。

試合進行の下の 招待した端末 に、発行した招待と登録された端末（機種・登録した時刻・最後に通信した時刻）の一覧が出ます。

  • 外された端末は、次の保存から採点できなくなります。端末に残っている未送信の採点は消えません。新しい QR で登録し直すと送られます。
  • 一覧は開いたときと ↻ 更新 で読み直します（自動では変わりません）。

運営のパスワードで開いている端末（今までどおりの使い方）は、何も変わりません。

採点画面の見方

採点は太刀の順番どおりに行います。 前の太刀（配点のある太刀）が 未 のままだと、後ろの太刀は薄く表示されて押せません。一ノ太刀から順に成功・失敗を付けていくと、次の太刀が押せるようになります。

一つの形で途中失敗したら、それ以降の太刀は自動で無効になります。 太刀を 失敗 にすると、同じ行のそれより後ろの太刀（配点のある太刀だけ）は押せなくなり、セルが灰色で「無効」とその太刀の元の点数（○ だったときの配点）が表示されます。無効になった太刀は0点として合計されるので、その形は最初の失敗より前に成功した太刀の点数（と補正点）だけが入ります。失敗を 成功 や 未 に戻すと、後ろの太刀も元どおり押せる「未」に戻ります（後ろの太刀に値が入っていた場合はまとめて「未」に戻ります）。失敗 ボタンは行のいちばん最初の「未」を失敗にするので、押すと残りの太刀がまとめて無効になります。以前に採点した選手を開き直したときも同じ規則で表示されますが、確定し直すまでは保存済みの得点は変わりません。

  • この大会は「準備中」です。運営画面で「試合開始」を押すと採点できます。 — 運営画面で状態を進めてから、この画面で大会を選び直してください。
  • この大会は「最終結果」です。得点は編集できません。運営画面で「戻す」を押すと編集できます。 — 確定後は、サーバーが得点の保存そのものを断ります。

採点できない状態のときは 確定 形成功 失敗 と得点・補正点・備考の入力が無効になります。前後の選手の移動・タイマーは使えます。

状態は端末どうしで自動には伝わりません。運営者が状態を変えたら、コートの端末では大会を選び直してください（選手を足したときと同じです）。

二巡目の並び順

二巡目の番号は、同じコート・同じ性別の中で、一巡目の得点が低い人から 1番・2番…と付きます。並べるのは確定済みの得点だけで（未確定は 0 点として先頭側）、同点のときは一巡目の試技順の番号（数として。10番は2番の後）で決まります。男子と女子は別々に数えます（例: A-男子-2-1 は A コートの男子で一巡目がいちばん低かった人）。一巡目とは出番の順が変わるので、番号を読み上げるときは気をつけてください。

並び方は画面で違います。コートの端末の選手一覧では二巡目の女子が先に並び、運営画面の試合進行タブ・選手登録タブ・PC の二巡目の形登録では男子が先に並びます。どちらも中身は同じで、出番はコートの端末の選手一覧の順です。

未採点が残ったまま 一巡目を終了 ▶ を押すと、並び順を正しくするための確認が出ます。並び順を正しくするため、なるべく全員の採点を終えてから押してください。

コートが決まっていない選手の二巡目は作れません。一巡目を終了すると コートが決まっていない（未分類の）選手が n 名います。二巡目には入っていません。 と知らせます。選手登録でコートを設定し、一巡目に戻して終了し直してください。

ベスト4

二巡目の試技順は、コートごと・部ごとに一巡目の得点が低い順です（システムが特別な組を作って最後に回すことはありません）。終盤にベスト4 に入りそうな選手を最後のほうに斬らせたいときは、運営者が採点画面の選手一覧（運営の端末の ⋮⋮）か選手登録で、ドラッグして試技順を入れ替えます。一巡目に戻して一巡目を終了し直すと、二巡目の試技順は一巡目の得点が低い順に付け直されます（手で入れ替えた順も付け直されます。二巡目にまだ誰も採点していないときだけ）。

ベスト4: 一般男子（新人を含む）の 合計（一巡目＋二巡目）の上位4名です。4位が同点なら同点の全員が入ります。合計0点以下の人は入りません。

  • 二巡目の途中は暫定ベスト4です。二巡目の採点が確定するたびに動き、残り n 名（二巡目がまだ確定していない一般男子の人数）を添えます。二巡目がまだの人は二巡目が「—」で、合計は一巡目だけです。
  • 全員が斬り終える（二巡目が全員確定する）か、最終結果にするとベスト4として確定します。
  • 見られる場所: 試合進行（PC・スマホ）、二巡目終了・表彰の要約、共有リンク、発表モード の ベスト4。順位表の一般男子の上位4名（合計1点以上）と同じ人・同じ順位です。

通信が切れても続けられます

採点はいったん端末に貯めてからサーバーへ送ります。電波が弱くても、採点そのものは止まりません。

  • ● 保存済み — サーバーまで届いています。
  • ◌ 保存中… — いま送っているところです。
  • ⚠ 未保存 3 件・再送中 — まだ届いていない採点があり、送り直しています。そのまま採点を続けてかまいません。
  • 最初の失敗から30秒たっても残っていると、上に ⚠ サーバーに保存できていません のバナーと 今すぐ再試行 ボタンが出ます。通信を確かめてから押してください。

貯めた分は端末の中（ブラウザの保存領域）にも控えます。電池切れやアプリの再起動で消えることはありません。次にその端末で採点画面を開くと 前回未送信の採点 n 件を送信します。 と出て、自動で送り直します。

控えはその端末のそのブラウザにしかありません。別の端末や別のブラウザからは送れませんし、ブラウザのサイトデータを消すと失われます。できるだけ ● 保存済み になってから閉じてください。未保存のままページを離れようとすると確認が出ます。

ほかの端末が書いた内容の取り込み

選手を切り替えたときと、ほかのアプリから採点画面に戻ってきたときに、サーバーから読み直します。運営画面や別のコートが付けた確定・備考・得点は、このときに画面へ入ります。

ほかの端末が同じ選手の採点を先に更新していると、保存のときに 別の端末で更新されています と確認が出ます。サーバーの内容を読み込む か この端末の内容で上書き かを選びます（あとで決める（端末に残す） を選ぶと、その採点は端末に残ったままになり、次にその端末で採点画面を開いたときや 今すぐ再試行 で送り直して、まだ衝突していればもう一度確認が出ます）。状態が進んで採点できなくなった巡目の採点も、同じように確認が出ます（ボタンは サーバーの内容を読み込む と この端末に残す）。

3. 得点の集計

得点の式

技ごとの得点 ＝ 成功した太刀の配点の合計 ＋ その技の補正点
選手の合計 ＝ 技ごとの得点の合計 ＋ 全体補正点
  • 「失敗」と「未」は0点です。打たない太刀（灰色のセル）も0点です。
  • 補正点は整数です。マイナスも入れられます。
  • 備考は得点に入りません。

技の配点を変える

配点は 技得点表（techniques.html）で大会ごとに変えられます。画面の上の 表示する対象 で大会を選び、✎ 編集する を押してから、技名ごとに 初太刀 から 四ノ太刀 までの点を入れ、保存 を押します。PC 用は左の 技得点表 から同じことができます。

  • 雛形（新規大会の初期値） を変えても、すでにある大会の配点は変わりません。雛形はこれから作る大会に入る初期値です。
  • 雛形に戻す を押すと、その大会の配点を雛形の内容で置き換えます。
  • 選手が使っている技の名前を変えて保存すると、選手の技名も新しい名前に付け替えて保存しますか？ と聞かれます（使っている人数が出ます）。OK で選手の技名も新しい名前になり、キャンセル なら保存しません。使っている技を消す・別の技に置き換える保存と、雛形に戻す で使っている技が無くなる場合は、付け替えができないので保存されません（技の名前を残すか、先に選手の技を変えてください）。
  • 別の大会からコピー で、ほかの大会の配点を表に読み込めます。保存 を押すまでは反映されません。
  • 技名の隣の 合計点 は初太刀〜四ノ太刀の配点の合計で、自動計算です（編集はできません）。右端の 備考 は技ごとのメモです（100 文字まで。得点には影響しません）。
  • 抜刀状態 は「抜刀してからの形」の印です。真剣レンタルの選手は、ここにチェックが付いている形だけを選べます。どの形を抜刀後とするかは大会ごとに運営が決めます（既定では 立位袈裟 立位逆袈裟 立位横一 座位袈裟 座位逆袈裟 座位横一 の6形に付いています）。
  • 回数制限 が「なし」の形（編集ではチェックが付いている形）は、同じ巡の中で1人が何度選んでも構いません（既定では上の抜刀後の6形だけ）。「あり」の形は、1人の3枠のうち同じ巡で1回までです（§1 の「技の選び方」）。
  • 減点初太刀 は、初太刀が減点扱いで成功したときの点です（胸尽くしなど、切先が鞘から抜けていた状態での成功）。空欄なら減点の状態そのものが出ません。数値を入れると、採点画面のその技の初太刀だけ 未 → 成功 → 減点 → 失敗 → 未 と一段増えます（既定では 胸尽くし(男) 胸尽くし(女) に4点）。
配点を変えても、すでに採点した選手の保存済みの得点は変わりません。変えたときは、その技を使った選手を採点画面で開き、技得点表の変更で点が変わります（保存 16 → 再計算 21） の表示が出たら 計算し直して保存 を押してください（確定済みの選手は確定し直しの確認が出ます）。開いただけでは保存済みの得点も一覧も書き換わりません。大会が始まってからの変更は避けてください。採点済みの選手がいる大会を開くと、画面に人数の注意が出ます。

部門と順位

  • 部門は 一般男子・一般女子・新人枠 の3つです。
  • 新人にチェックが付いた選手は、新人枠にも、男子または女子の部にも入ります。どちらか一方ではありません。
  • 順位は同じ選手の一巡目と二巡目の得点を足し合わせて付きます。つまり一巡目と二巡目の合計で並びます。
  • 同点は同順位です。同点が2人いたら、次の人は3位になります。
合算は一巡目の行ごとに行います（二巡目の行は、元になった一巡目の行につながっています）。同姓同名の別人がいても、別々の行として並びます。一巡目の行の名前・性別・新人を直すと、つながる二巡目の行にも写ります。元のつながりを持たない古いデータの二巡目の行だけは、同じ名前・同じ性別の一巡目の行に足します。

5. 困ったとき

「この QR は期限切れです／取り消されています」と出る

QR を読み取って開いた画面に出る案内です。運営に新しい QR を出してもらい、読み取り直してください（運営画面の 試合進行 → コートのカードの 📱 この端末を招待（QR））。

「登録できる端末の数に達しています」と出る

その QR で登録できる台数をすでに使い切っています。運営が 招待した端末 の一覧から古い端末を この端末を外す で外すか、新しい QR を出してください。知らない端末が入っていたら、外すと同時に QR の取り扱い（写真で送っていないか）も確かめてください。

「この端末は採点専用です」と出る

採点端末として登録した端末で、運営画面など採点以外のページを開いたときの案内です。運営画面は運営の端末で開いてください。この端末の登録を解除したいときは、画面の この端末の登録を解除する を押します（そのあと運営の ID・パスワードを聞かれるようになります）。

「この端末の採点の登録が切れました」と出る

期限が来た、運営が外した、招待が取り消された、のどれかです。未送信の採点は端末に残っています。運営に新しい QR をもらって読み取ると、残っていた採点が送られます（再読み込みしても直りません）。

「技が未入力です。運営画面の試合進行で技を入力してください。」と出る

その選手にまだ技が入っていません。運営画面の 試合進行 タブ（スマホ用）でその選手の ① ＋ ② ＋ ③ ＋ をタップして技を入れてください（PC 用は二巡目なら 二巡目の形登録、一巡目なら 選手登録 の表）。一巡目と同じ形に戻す でもかまいません。

「内訳を復元できません（技の数が変わっています）。」と出る

採点したあとで技の数が変わった選手です。前の内訳はもう表に戻せません。その場で採点し直してください。

表に触ると 記録済みの n点 を、いま入力する内容で置き換えます。よろしいですか？ と確認が出ます。OK を押してから採点し直してください。

採点し直すまでは、その選手のデータは書き換えられません。選手を切り替えても得点は消えないので、あわてなくて大丈夫です。備考 だけは、復元できない選手でもそのまま保存できます。

「⚠ 未保存 n 件・再送中」が消えない

サーバーに届いていない採点が残っています。

  1. 端末の通信（Wi-Fi・電波）を確かめる。
  2. 端末を閉じずにそのまま待つ。つながれば自動で送られます。
  3. バナーの 今すぐ再試行 を押す。

閉じてしまっても、同じ端末の同じブラウザで採点画面を開き直せば 前回未送信の採点 n 件を送信します。 と出て送り直せます。ただし別の端末からは送れないので、できるだけ ● 保存済み になってから閉じてください。

「保存できなかった採点が n 件あります」と出る

送ろうとした選手が、サーバーの名簿からいなくなっています。名簿を 置き換える で入れ直した直後や、その選手を選手登録タブで削除したあとに起きます。入れ直すと選手の ID が変わるため、その前に採点していた分は送り先を失います。

ダイアログに選手 ID と点数が並びます。該当する選手を採点画面で開き、採点を確認して入力し直してください。

技が見つからない

技を選ぶシートの絞り込みに出てこない、あるいは採点表の行がまるごと灰色になるときは、その技名が 技得点表 にあるか確かめてください。配点は大会ごとなので、その大会を選んでから確かめます（画面の上の 表示する対象）。PC 用は左の 技得点表 です。

技得点表では行を足せません。できるのは、すでにある行の技名と配点を書き換えて 保存 するか、雛形なら デフォルト設定に戻す、大会なら 雛形に戻す のどちらかです。

対処は2つあります。

  1. 使っていない行の技名と配点を書き換えて 保存 する。
  2. 選手の技を、リストにある名前に直す。運営画面の選手登録タブで選手をタップ → 選手を編集 のシートで技の枠から選び直します。

技名は完全に一致したものを探します。CSV の取り込みと選手の保存では前後の空白を自動で取りますが、それでも技得点表に無い名前の選手は、採点画面でその行が赤く警告され、その選手の保存・確定ができません（記録は消えません）。技得点表の名前に合わせて選手の技を直してください。使っている技を技得点表で改名したときは、保存の確認で選手の技名も付け替えられます。

二巡目の形はどこで登録するのか

二巡目で形を変える選手がいるときは、大会の前に、一巡目の行の 二巡目の形（PC 用の選手登録の表の列）／二巡目の技（スマホ用の編集シート）に入れておきます。Excel の名簿からは、貼り付け（13 列）か簡易形式の CSV の 二巡目技①②③ の列で入れられます。空なら一巡目と同じ形です。一巡目を終了すると、その形で二巡目の行ができ、当日の変更は 二巡目の形登録 で直せます。

「二巡目を開始できません。」と出る・「二巡目を開始 ▶」が押せない

二巡目の行に、技得点表に無い技・回数制限が「あり」の同じ形の2回以上・レンタルの選手が選べない形（抜刀状態でない形）が入っています。PC 用では 二巡目を開始 ▶ が押せなくなり、工程表に 二巡目を開始できません。形登録で直してください。（二巡目の形登録 の区画では …下の表で直してください。）と人数・名前が出ます。スマホ用では押したときに同じ文言で止まります。二巡目の形登録（スマホ用は 試合進行 タブ）でその選手の技を直すと、PC 用はボタンがまた押せるようになります。直してから、もう一度 二巡目を開始 ▶ を押してください。

二巡目ができていない

一巡目を終了 ▶ を押すと自動でできます。できていなければ一巡目に戻してもう一度押してください。一巡目の選手が1人も登録されていないか、通信が切れている場合もできません。選手登録タブと端末の通信を確かめてください。コートが決まっていない選手の扱いは §2「二巡目の並び順」を見てください（その選手の二巡目は作られません）。

選手の CSV を取り込めない

  • CSV の文字が化けていて読み取れませんでした。 — UTF-8 でも Shift_JIS でも読めませんでした。Excel なら CSV UTF-8（コンマ区切り） で保存し直してください。
  • CSV の 1 行目（見出し）が、読み込める形式と合っていません。 — 1 行目を簡易形式（名前 コート 性別 技① … 二巡目技① 二巡目技② 二巡目技③）か、結果確認の CSV エクスポート の見出しにそろえてください。列を足す・抜く・並べ替えると読めません。
  • 二巡目がある大会には、結果確認の CSV エクスポートで書き出した形のファイル（23 列。以前の 20 列も可）だけ取り込めます（置き換え・追記とも）。 — 二巡目の行がある大会を別の形の CSV で取り込むと、一巡目とのつながりが切れた行ができるため断ります。エクスポートしたファイルを使ってください。
  • 取り込む間に選手の人数が変わりました — 確かめている間に他の端末が選手を足した・消したときです。何も消さずに画面を読み直します。内容を確かめて、もう一度取り込んでください。

大会のファイルを取り込めない

  • ファイルを読めませんでした。 — 選んだファイルがこのアプリの書き出したものではありません。CSV や画像ではなく、tameshigiri_…json を選んでください。
  • このアプリのエクスポートファイルではありません。 — 中身は JSON ですが、このアプリの形式ではありません。⋯ → 💾 ファイルに保存 で作ったファイルか確かめてください。
  • 対応していないファイル形式です（version: …） — 新しい版のアプリが書き出したファイルです。取り込む側のアプリを更新してください。
  • そのほかの理由（大会名が空、選手が多すぎる、技リストの n 行目が不正）はそのまま画面に出ます。書き出した側でその大会を直してから、もう一度保存し直してください。

  • 運営画面（スマホ用 admin.html） — 右上の ⋯ → ❓ ヘルプ。

6. AI 用キー（AI に操作させる）

何ができるか

Claude Code などの AI に、この大会運営サーバーを操作させるためのキーです（運営の ID・パスワードとは別のものです）。キーを持つ AI は、次のことだけができます。

  • 本番の大会は読むだけです（大会の一覧・選手・得点・順位）。書き換えや削除はできません。
  • 書き込めるのは、名前が 「テスト用」で始まる大会だけです（大会の作成・選手の登録・採点・状態の進行・削除。予行演習用）。
  • 運営の画面（運営・技得点表・招待・キーの発行）は開けません。

大会名を「テスト用」で始まる名前に変えて保存するときは、運営画面（基本情報）が「AI が書き込める大会になります」と確認します。トップの大会一覧には AI 書込可 の印が付きます。

発行と取り消し（運営画面・PC 用）

  1. PC 運営の 基本情報 の末尾の AI 用キー で 🔑 発行する を押します（ラベル・期限。期限は 30 日が標準で、最大 90 日）。
  2. キーは発行したときの 1 回だけ表示されます。キーをコピー で写します。
  3. 自分の PC のターミナル（Claude Code の外）で、画面に出ているコマンド（set-key.ps1）を実行し、キーを貼り付けます。キーは Windows の資格情報マネージャーに保存され、AI を動かす MCP サーバーだけが読みます。
  4. 一覧の 取り消す で、いつでも使えなくできます。最後に使われた時刻と回数も一覧で分かります。
キーを Claude のチャットに貼らないでください。Claude にはキーを渡しません（渡す必要もありません）。他の人にも見せないでください。心当たりのない利用があれば、すぐ取り消してください。
