# Antigravity Custom Skills

このリポジトリは、Antigravity（エージェントAIコーディングアシスタント）の機能を拡張するためのカスタムスキルのコレクションです。

## 含まれるスキル

### 1. `self-healing-executor`
コマンドの実行やテストを行い、エラーが発生した場合にログを自動で解析して自己修復（コードのパッチ適用と再試行）を行うスキルです。不安定なビルドやテストのデバッグにおいて、自動的に原因究明から修正までを行います。

**使い方:**
Agentに以下のように指示して呼び出します。
> 「`self-healing-executor`スキルを使って、`npm run build` を実行し、エラーが出たら自律的に修正して通るようにして」

### 2. `requirement-architect`
ユーザーの漠然とした要件から、具体的なアーキテクチャ設計（Blueprint）、データモデル、API設計、および実装計画を自動生成するソフトウェアアーキテクトスキルです。コーディング前の要件定義や設計をスムーズに構築します。

**使い方:**
Agentに以下のように指示して呼び出します。
> 「`requirement-architect`スキルを使って、次期アップデートで追加する『ユーザー間メッセージング機能』のアーキテクチャと実装計画を作成して」

## 導入方法

これらのスキルを現在作業中のAntigravity環境（ワークスペース）で利用するには、以下のいずれかの方法で組み込みます。

### 方法A: ワークスペースへ直接コピーする（推奨）
このリポジトリの `.agent/skills` の中身を、作業中のプロジェクトの `.agent/skills` フォルダ内に配置します。

```bash
# コピー元（このリポジトリ）からプロジェクトのスキルドディレクトリへコピー
cp -r path/to/antigravity-skills/.agent/skills/* ./dojo-core/.agent/skills/
```

### 方法B: Git Submoduleとして追加する
ワークスペースが既にGit管理されている場合は、サブモジュールとして追加して最新のスキル構成を追従できるようにすることも可能です。

```bash
# プロジェクトルートで実行
git submodule add https://github.com/yet103/antigravity-skills.git .agent/external-skills

# 必要に応じて .agent/skills ディレクトリにシンボリックリンクなどを張って利用します
```

## 各スキルの構成
スキルは独立したディレクトリとして管理されており、その中にスキルのメタデータやプロンプトの指示を記述した `SKILL.md` が含まれています。Agentはこれを読み取ることで特殊な行動計画を実行します。
