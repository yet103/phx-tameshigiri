# Requirement Architect

## Overview
This skill helps in transforming ambiguous user requirements into concrete, technical designs. It breaks down the problem, creates step-by-step implementation plans, and defines component responsibilities.

## Usage
Simply provide the end goal or feature request. The architect will output a comprehensive design document before coding begins.
