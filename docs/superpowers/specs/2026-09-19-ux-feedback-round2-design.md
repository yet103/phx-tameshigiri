# UX 見直しへの修正要望（第 2 回）: 技の選択肢を性別で絞る

**日付**: 2026-09-19
**対象**: phx-tameshigiri（試し斬り採点システム）
**前提となる設計書**: [2026-09-19-ux-feedback-round1-design.md](2026-09-19-ux-feedback-round1-design.md)

「技選択で男と女で縛られているものは選択肢から除外（自動）」への対応。

## 現状

- 技リストには `胸尽くし(男)` / `胸尽くし(女)`、`水月(男)` / `水月(女)`、`破図味(男)` / `破図味(女)` のように、名前の末尾 `(男)` `(女)` で配点が分かれる組がある（`data.js` と大会ごとの `techniques`）
- 選手に保存する技名は接尾辞なし（`破図味`）。採点画面の `Scoring.findTechnique(name, isFemale)` が「完全一致 → 性別の接尾辞付き」の順で解決する
- 選択 UI（PC 選手登録のセレクト、PC 試合進行の二巡目の表のセレクト、スマホの `TechPicker`）は技リストをそのまま並べるので、`破図味(男)` と `破図味(女)` の両方が出る。選ぶと接尾辞付きの名前が保存され、あとで性別を変えると別の配点になる
- 貼り付け（`Courts.parsePasteRows`）とサーバーの一括登録（`POST …/players/bulk` の `rows`）は技名を技リストと**完全一致**で照合するため、接尾辞なしの `破図味` を「技リストにありません」と拒む（採点画面は解決できるのに登録で弾かれる不整合）

## 決定

| 論点 | 決定 |
|---|---|
| 選択肢 | **選手の性別で絞り、接尾辞を外した名前で 1 つだけ出す**。女子には `(男)` の技を出さず、男子には `(女)` の技を出さない。接尾辞のない技はそのまま |
| 保存する名前 | **接尾辞なし**（`破図味`）。採点画面が性別で解決する既存の作法に統一 |
| 表示する配点 | 接尾辞を外したあとも、その性別の配点（`(女)` の `strikes`）を出す |
| 検証 | 貼り付けとサーバーの一括登録は「接尾辞なしの名前が、その性別で解決できるか」で照合する。接尾辞付きの名前もそのまま受ける（完全一致） |
| 既存データ | 接尾辞付きで保存されている技名（`破図味(男)` など）はそのまま動く（完全一致で解決）。セレクトでは「（リストに無い技）」ではなく、その名前を選択肢に足して表示する。書き換えは行わない |
| 性別を変えたとき | 接尾辞なしの名前なので配点だけが変わる。採点済みなら既存の警告（`Courts.scoreMayChange`）が出る |

## 純粋関数

`courts.js` に置き、`test.html` で固定する。サーバー（`server/index.js`）は同じ規則を自前で持つ（`status.js` と同じ理由。テストで両方を固定）。

```javascript
Courts.techniqueOptions(techniques, isFemale)
// → [{ name, strikes }]  選択肢。元の並び順を保つ
//   ・名前の末尾が (男)/(女) でない技: そのまま
//   ・末尾が性別と一致する技: 接尾辞を外した名前で。同じ名前がすでにあれば足さない
//   ・末尾が性別と一致しない技: 出さない
Courts.resolveTechnique(techniques, name, isFemale)
// → 技 | null  Scoring.findTechnique と同じ規則（完全一致 → name + '(男)'/'(女)'）。
//   courts.js は scoring.js に依存しないので自前で持つ
Courts.stripGenderSuffix(name)   // '破図味(男)' → '破図味'。接尾辞が無ければそのまま
```

サーバー: `POST /api/events/:id/players/bulk` の `rows` の技名検証を `resolveTechnique` 相当（完全一致 → 性別の接尾辞付き）に変える。`row.isFemale` で解決する。行番号つき 400 の文言は変えない。

## 画面

| 場所 | 変更 |
|---|---|
| PC 選手登録 `desk-players.js` | 技1〜3 のセレクトの候補を `Courts.techniqueOptions(ctx.techniques, p.isFemale)`。性別を変えて保存したら、その行の技セレクトを作り直す（候補が変わる）。保存済みの技名が候補に無ければ（接尾辞付きの旧データなど）その名前を選択肢に足す |
| PC 試合進行 `desk-match.js` | 二巡目の表の技セレクトも同じ。行ごとの「一巡目と同じ技をコピー」と全員コピーは、コピー元の名前をそのまま（接尾辞は外さない。一巡目と同じ名前が正） |
| 貼り付けダイアログ `desk-players.js` / `courts.js` | `parsePasteRows` の技名照合を `resolveTechnique(techniques, name, row.isFemale)` に。接尾辞付きも受ける。保存する名前は貼られたまま |
| スマホの `TechPicker`（`techpicker.js`、`admin-players.js` と `admin-round.js` から） | 開くときに渡す `techniques` を `Courts.techniqueOptions(list, isFemale)` にする。`TechPicker` 自体は変えない（渡された配列を並べるだけ）。配点の表示は絞った配列の `strikes` を使うのでそのまま正しい |
| 技と配点の編集（`techedit.js`） | 変更なし（技リストの編集では `(男)` `(女)` の名前をそのまま扱う） |
| ヘルプ | 「技の選び方」に「男女で配点が分かれる技は、選手の性別に合う方だけが出る」を 1 文 |

## テスト（`test.html`）

1. `techniqueOptions`: `data.js` の既定リストで女子 → `胸尽くし` `水月` `破図味` が接尾辞なしで各 1 つ、`strikes` が `(女)` の値。男子 → `(男)` の値。接尾辞なしの技は両方に出る。並び順が元のまま
2. `resolveTechnique`: `破図味` + 女子 → `破図味(女)`、`破図味(男)` + 女子 → 完全一致で `破図味(男)`、無い名前 → null
3. `parsePasteRows`: 女子の行で `破図味` が `ok: true`、男子の行で `胸尽くし` が `ok: true`、`破図味(女)` も `ok: true`、無い名前は従来どおり `ok: false`
4. サーバー: `createPlayersBulk({rows})` で `isFemale: true` の行の `tech1: '破図味'` が 201、`tech1: '無い技'` が 400
5. 既存テストがすべて通る（現在 877）

## 手動確認

- PC 選手登録で女子の行の技セレクトに `破図味` が 1 つだけ出て `(男)` が無い。男子に変えると候補が `(男)` の配点に変わる（配点は表示されないので、採点画面で確認）
- 接尾辞付きで保存された旧データの行（`Api.updatePlayerInfo` で `tech1: '破図味(男)'` を入れて作る）がセレクトに表示され、保存し直さなければそのまま
- スマホの技ピッカーで女子の選手に `(男)` の技が出ない
- 貼り付けで女子の行に `破図味` を入れて登録できる
- 採点画面で女子の `破図味` の配点が `(女)` の値（二ノ太刀 6 点）
