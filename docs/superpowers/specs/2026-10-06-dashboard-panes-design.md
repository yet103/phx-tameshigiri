# ダッシュボードの面を閉じる・再表示・ドラッグで入れ替え（設計）

日付: 2026-10-06
ユーザー要望: 「ダッシュボードで四つあるパネルそれぞれ、× で消すことができるように（うまいこと再表示メニューもつけて）。あと、場所をドラッグで入れ替えることもできるように。」

前提の設計書: `2026-10-05-dashboard-design.md`（面＝コートごとの採点・運営・順位の iframe、仕切りのリサイズ、閲覧専用の盾）。

## 1. 決めたこと（ユーザーが不在のため、実装側で決めた前提）

- **閉じる**: 各面の見出しの右端に「×」。押すとその面が消え、同じ段の残りの面が幅いっぱいに広がる。段の面が全部消えたらその段ごと消え、もう一方の段が窓いっぱいになる。全部消えたら「すべての面を閉じています。上の ▦ 面 から表示できます。」の案内だけ出す。
- **再表示メニュー**: 上の帯の縮小率の右に「▦ 面」ボタン。押すと面の一覧（チェックボックス。付いている＝表示中）が開く。外すと閉じる・付けると出る。下に「すべて表示」「並びを元に戻す」。外側クリックか Esc で閉じる。
- **ドラッグで入れ替え**: 面の見出し（×以外）を掴んで別の面の上で放すと、2 つの面の場所が入れ替わる（段をまたいでもよい。例: A コートと順位を入れ替え）。掴んでいる間は元の面が薄くなり、放せる面に金の枠が付く。
- **iframe は読み直さない**: 閉じる＝`display: none`（中の採点欄は保ったまま）、入れ替え＝位置だけ変える。そのため面は DOM の順番ではなく **絶対配置**で並べる（§3）。
- **端末に覚える**: 閉じた面と並びは localStorage `tmg_dashboard_panes`。仕切りの幅は従来の `tmg_dashboard_layout`（段の面の数ごとに控えるキーを拡張）。
- 面の鍵（key）: コートは `court:<コート名>`、運営 `desk`、順位 `rank`。大会をまたいで同じ（コート名が同じなら同じ並び・同じ非表示）。コートが無い大会の「コートがありません」の案内は鍵 `nocourt` の面として上段に出す（閉じられない・掴めない・メニューに出ない）。

## 2. データ

```
tmg_dashboard_panes = { top: [key...], bottom: [key...], hidden: [key...] }
tmg_dashboard_layout = { row: 上段 %, cols: { top1|top2|top3…: [%...], bottom|bottom1|bottom3…: [%...] } }
```

- `arrangePanes(keys, defaultTop, defaultBottom, saved)`: 控えの top/bottom から今の大会に無い鍵を落とし、控えに無い鍵は既定の段の末尾に足す。hidden は今ある鍵だけ残す。壊れた控えは既定。
- `swapPanes(arr, a, b)`: a と b の場所を入れ替える（同じ段でも別の段でも）。片方が無ければそのまま。
- `rowKey(row, n)`: 幅の控えのキー。`top<n>`。下段は 2 面なら従来どおり `bottom`、他は `bottom<n>`（既存の控えと互換）。
- `paneRects(layout, topN, bottomN)`: 表示中の面の数から、各面と仕切りの位置を %（仕切りの px は別勘定）で返す純粋関数。段が片方だけなら縦の仕切り無しでその段が 100%。

## 3. 画面（絶対配置）

- `.dash-grid` を `position: relative` にし、面と仕切りを直下の絶対配置にする。`left/top/width/height` は `calc((100% - 仕切りの本数×8px) × 割合 + 手前の仕切りの本数×8px)` で入れ、窓のリサイズは CSS に任せる（JS の resize 監視は無し）。
- 面の要素は大会を選んだときに 1 回だけ作る。閉じる・再表示・入れ替え・仕切りの移動は `applyPositions()` で style を当て直すだけ。仕切りの要素は本数が変わるので作り直す（iframe は含まないので安い）。
- 仕切りのドラッグは従来どおり（`dragCols` / `dragRow`）。キーは `rowKey` で表示中の数に合わせる。
- 面の入れ替えは見出しの pointerdown → 6px 動いたらドラッグ開始（`body.dash-dragging` で iframe の pointer-events を切るのは仕切りと同じ）→ `document.elementFromPoint` で下の面を探して印 → pointerup で `swapPanes` → 保存 → 当て直し。

## 4. テスト（test.html）

`arrangePanes`・`swapPanes`・`rowKey`・`paneRects`・`loadPanes/savePanes`（壊れた控え）を純粋関数として検証する。

## 5. ヘルプ

help.html のダッシュボードの項に、× で閉じる・▦ 面 で戻す・見出しをドラッグで入れ替える、を足す。
