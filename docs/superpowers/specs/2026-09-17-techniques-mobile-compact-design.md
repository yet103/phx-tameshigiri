# 技マスタ編集画面のスマホ向け狭表示 設計書

作成日: 2026-09-17

## 目的

技マスタ編集画面（`techniques.html`）を、スマホの縦持ち（幅 375px 前後）でも
横スクロールなしに「技名〜四ノ太刀」まで一度に見え、かつ 1 画面に並ぶ技の数を
増やした状態にする。

## 現状と問題

`style.css` の `.tech-table` 節（技術リストテーブル）は、画面幅にかかわらず

- セル余白 `6px 10px`
- 技名入力 `width: 120px`、配点入力 `width: 60px`

で固定されている。375px 幅（`.container` の左右余白を引いて有効幅 351px）では
表全体が約 466px になり、`overflow-x: auto` の親で横スクロールになって
「四ノ太刀」列が隠れる。また 1 行が約 36px あり、余白の分だけ並ぶ技が少ない。

## 方針（案 A：スマホ幅だけ CSS で詰める）

PC 幅（768px 以上）の見た目は変えず、`@media (max-width: 767px)` で
`.tech-table` の寸法だけを詰める。HTML・JS は変更しない。

### 変更内容（`style.css` 技術リストテーブル節の直後に追加）

| 対象 | 現状 | スマホ幅 |
|---|---|---|
| `th, td` の余白 | `6px 10px` | `3px 2px` |
| 見出し `th` の文字 | 14px（body 既定） | `12px`（「四ノ太刀」4 文字が 1 行に収まる） |
| 配点入力 `input[type="number"]` | `60px` | `44px` |
| 技名入力 `td:first-child input[type="text"]` | `120px` | `width: 100%; min-width: 0`（列の残り幅いっぱい） |
| 技名列 `td:first-child` | 自動 | `width: 100%`（残り幅を技名列に寄せる） |

幅の見積もり（375px、有効幅 351px）：
配点列 = 44（入力）+ 4（余白）+ 1（罫線）≒ 49px × 4 = 196px、
技名列 = 351 − 196 ≒ 155px。合計が有効幅に収まり横スクロールは出ない。
見出し「四ノ太刀」は 12px × 4 文字 = 48px ＋ 余白 4px = 52px で、
配点列 49px を超えるため列幅は見出し基準で約 53px となり、
4 列で約 212px、技名列は約 139px。それでも合計 351px 以内。

高さの見積もり：余白 6px → 3px で 1 行 ≒ 36px → ≒ 30px。
同じ画面高さで並ぶ技が約 2 割増える。

### 変えないもの

- PC 幅の表（既存の寸法のまま）
- 見出しの表記（「初太刀／二ノ太刀／三ノ太刀／四ノ太刀」。採点画面・技選択シートと揃える）
- 入力欄の最小タップ高さ（現状も `min-height` 指定なし。入力欄は指で押すものだが、
  数値入力は直接タップして数字を打つ用途なので現状どおり 44px は要求しない）

## テスト

自動テストの対象（`test.html`）は API と計算ロジックで、見た目は対象外。
次を手動（ブラウザのモバイル表示）で確認する。

1. 375px 幅（iPhone 相当）で `techniques.html` を開き、横スクロールなしに
   「四ノ太刀」列の入力欄まで見えること
2. 見出し「四ノ太刀」が 2 行に折れないこと
3. 360px 幅（Android 小型）でも 1. と 2. が成り立つこと
4. 768px 以上では変更前と見た目が変わらないこと
5. ダークテーマでも崩れないこと

## 影響範囲

- `style.css`（技術リストテーブル節にメディアクエリ追加）のみ
- `.tech-table` を使う画面は `techniques.html` だけ
