# 男女を分けずに進める大会（混合）と、出走番号を画面から消す

日付: 2026-10-07
ユーザー要望: 「試合進行ですが男女の部は分けずに、混合で進めるとのことです。大会作成時のオプションで、男女を分ける、分けない選べたでしょうか？」→ 選べない（男女分けはコードに固定）と確認 → 「1 は進行の見た目だけで OK。出走番号は通しで OK。大会ごとの切り替えとしたい」→ 「出走番号は画面表示しないでいいとおもうのですが」→ 影響を提示 → 「OK です」。

## 1. 決めたこと

- **大会ごとに「男女を分けずに進める（混合）」を選べる**。大会の settings に `mixed`（真偽値。既定 false）を足す。既存の大会は mixed 無し＝従来どおり男女を分ける。
- **混合で変わるのは進行の見た目と出走順だけ**。順位の部門（一般男子・新人枠・一般女子）・ベスト4・配点・表彰・ダッシュボードは変えない。性別は従来どおり各行の `isFemale` に持つ。
- **出走順は男女通し**。混合大会では コート×巡目 を 1 つの組として、男女を区別せず 1 から番号を振る。
- **出走番号は画面に出さない（全大会で一律）**。選手登録の No. 列、採点画面の帯の「3番」と一覧の「順番」列、試合進行のカードの「順番」列、配信ボードの「3番」を消す。データ（order・CSV の「順番」列・大会ファイル）には残す。呼び出しはゼッケンを前提にする。
- **切り替えは準備中（draft）だけ**。試合開始の後は変えられない（採点画面の巡回が order の並びに乗っているため）。

## 2. order の書式

いまの order は `コート-性別-巡目-番号`（`A-男子-1-3`）。性別の段は `男子` / `女子`。

混合大会では性別の段を **`混合`** にする（`A-混合-1-3`）。

- データ自身が「混合」を語るので、order を読む側（並び順・ドラッグの組・採点画面の帯・配信ボード）は「混合」を 1 語受け入れるだけで動く。設定の旗を画面の隅々に配る必要が無い。
- 書式の正規表現は `^([^-]+)-(男子|女子|混合)-(\d+)-(\d+)$`。サーバー `ORDER_PATTERN`（server/index.js）、`Courts.orderKey`（courts.js）、app.js `updatePlayerLabels`、board.js の順番の表示、test.html の同じ正規表現をすべて揃える。
- `Courts.orderKey` の `sex` は 男子 0・女子 1・混合 0・読めない 2。混合の行は同じ組の中で sex が同じなので、並びは 巡目 → コート → 番号 だけで決まる。
- 性別の段を決める 1 か所: サーバーに `genderSeg(event, isFemale)` を置き、`event.settings.mixed === true` なら `'混合'`、そうでなければ `isFemale ? '女子' : '男子'`。`buildOrder` / `nextOrderNumber` の呼び出しはこの関数を通す（`buildOrder(court, isFemale, round, n)` は `buildOrder(court, seg, round, n)` に変える）。

### 試さなかった案

- order は `A-男子-1-3` のまま番号だけ通しにする: 並び順が「男子が先」のまま残らないよう、order を読む側すべてに大会の旗を配る必要があり、採点画面・ダッシュボード・配信ボードまで受け渡しが広がる。見落とすと通し番号と並びが食い違う。
- 全大会を混合に固定する: ユーザーは大会ごとの切り替えを希望。

## 3. 設定の画面と、切り替え時の振り直し

### 画面（desk-setup.js・admin.js）

「ゼッケン番号を必須にする」「級位・段位を必須にする」の並びに **「男女を分けずに進める（混合）」** のチェックを足す。他の設定と同じく、開いた時点から変わったときだけ `settings.mixed` を送る（キーごとの部分更新）。

- 準備中（draft）以外では無効（disabled）にし、注記「試合開始の後は変えられません」を出す。
- 保存の前に、選手がいるときは確認する: 「出走順を男女通しに振り直します。並びは今のまま（男子 → 女子）です。よろしいですか？」（戻す向きは「男女それぞれで振り直します」）。

### サーバー（PATCH /api/events/:id の settings）

- `mixed` は `requireBib` と同じ扱い（送られたキーだけ変える。真偽値でなければ false）。
- `mixed` が **変わる** とき、状態が draft でなければ 409（`reason: 'mixed_locked'`、「試合開始の後は男女の分け方を変えられません」）。
- `mixed` が変わるとき、全行の order を振り直す `renumberForMixed(event)`:
  - 混合にする向き: 今の並び（`compareRound1Order` と同じ 巡目 → コート → 男子 → 女子 → 番号）のまま、コート×巡目 ごとに 1 から通し番号。性別の段は `混合`。
  - 戻す向き: 今の並び（コート×巡目の番号順）のまま、コート×巡目×性別 ごとに 1 から。性別の段は行の `isFemale` から。
  - order が読めない行（CSV 由来の空 order など）は触らない。
  - 振り直しは `rev` を上げない（得点や技は変わらない。採点画面は order の変化を再読込で拾う）。
- 大会ファイルの取り込み・コピー・テンプレートからの作成・エクスポートで settings を写す 4 か所（1687・1806・3633・3770 付近）に `mixed` を足す。テンプレートは mixed: false。

## 4. 採番と並べ替え（サーバー）

`nextOrderNumber(players, court, seg, round)` の性別の引数を「性別の段」にし、混合では `'混合'` を渡す。呼び出しは全部で 10 か所（選手の追加・一括登録 2 種・CSV 取り込み・選手の更新 2 か所・二巡目生成 2 か所・並べ替え）。それぞれ `genderSeg(event, isFemale)` を通す。

- **並べ替え（POST …/players/reorder）**: 組の判定を `parsed.gender === seg`（seg は genderSeg）にする。body の `isFemale` は混合では見ない。
- **選手の更新（PATCH …/players/:pid）**: 混合では性別を変えても order は変えない（性別の段が `混合` のまま）。分ける大会では従来どおり性別の段が変わる。
- **二巡目生成（generateNextRound）**: `compareForRound2` の「女子が先」は分ける大会だけ。混合では一巡目の確定得点が低い順を男女通しで並べ、同点は一巡目の試技順。
- **CSV 取り込み**: 簡易形式（順番列の無い CSV）はサーバーが採番するので、取り込んだ大会の設定（混合か分けるか）で採番される。拡張形式（順番列のある CSV）は order をそのまま使うので、性別の段が大会の分け方と食い違う CSV（混合の大会の `A-混合-1-3` を分ける大会へ、またはその逆）は取り込めない。1 行でも食い違えば何も保存せず 400 `{ error: '男女の分け方（混合）が違う大会の CSV です。…', reason: 'mixed_mismatch' }` を返し、基本情報の「男女を分けずに進める（混合）」を合わせてから取り込み直してもらう。拡張形式の「一巡目の行」の照合は order の文字列一致なので、同じファイルの中で整合していればよい。
- **一括登録の簡易 CSV（CSV_SIMPLE_COLS）** の「性別」列は従来どおり `isFemale` に入る。

## 5. 画面（クライアント）

### 試合進行（desk-match.js）

- 分ける大会: 従来どおり「男子の部 一巡目」「女子の部 一巡目」の組。
- 混合: 巡目ごとに 1 組（見出しは「一巡目」「二巡目」。部の名前は付けない）。`courtCards(ctx, round, female)` の `female` を渡さない（`undefined`）と性別で絞らないので、組の列挙を `ctx.event.settings.mixed` で切り替える。`livePlayerFor` は `row.female` が無ければ性別を見ない（今のまま）。
- カードの選手表から「順番」列を消す（並びは今のまま試技順）。

### 選手登録の表（desk-players.js）

- 帯は コート×巡目（混合）／ 男子の部・女子の部 × コート×巡目（分ける大会）。混合では帯の見出しに部の名前を付けない。
- **No. 列を消す**。並べ替えは見出しを押して選ぶ仕組みなので、「巡」の列に `key: 'order'` を付けて、その見出しを押すと試技順で並ぶようにする（絞り込みの ▼ は今のまま。名前の列と同じく並べ替えと絞り込みを両方持つ）。既定の並びは今と同じ `order` の昇順。ドラッグ並べ替えは「試技順の昇順のとき」だけ可（今の条件の文言を「試技順（巡の列）のときに並べ替えできます」に）。ドロップ後に No. のセルを書き換える `renumberShown` は不要になる（行の位置だけ動かす）。
- 混合では **性別の列を行ごとに変えられる**（セレクト。今の sexCell は読み取り専用）。性別を変えても order は変わらない（§4）。分ける大会では従来どおり読み取り専用。
- 混合の「＋ 行を追加」は表の末尾に 1 つ（帯ごとではない）。下書き行でコートと性別を選ぶ（性別は既定 男子）。
- ドラッグの組（`Courts.reorderGroupKey`）は `court|sex|round` のままでよい（混合は sex が全行 0 なので コート×巡目 の組になる）。

### 採点画面（app.js）

- 帯の 1 行目: 分ける大会「男子の部　一巡目　A コート」、混合「一巡目　A コート」（部を付けない）。「3番」は消す。ゼッケンは今のまま「No.12」で出す。
- 一覧の「順番」列を消す。帯（`player-list-band`）は混合では性別で切らず巡目だけ（「一巡目」）、分ける大会では今のまま。
- 巡回（次の選手・前の選手）は `Courts.listForStatus` の並び＝order の並びのまま。

### 配信ボード（board.js）

「男子 1巡目 3番」→ 分ける大会「男子 1巡目」、混合「1巡目」。番号は出さない。

### ダッシュボード・順位表・表彰・共有

変えない（性別は `isFemale` で分けているため）。

### ヘルプ（help.html）

- 基本情報の設定に「男女を分けずに進める（混合）」の一節（準備中だけ変えられる、振り直し、通し番号は画面に出ない）。
- No.・順番の説明を消し、呼び出しはゼッケンで、と書く。古い画像はそのまま（申し送り）。

## 6. テスト（test.html・サーバー API テスト）

- `Courts.orderKey` / `roundOf` / `compareOrder` が `A-混合-1-3` を読む。混合の並びは 巡目 → コート → 番号。
- `reorderGroupKey` が混合で コート×巡目 の 1 組になる。
- サーバー: `renumberForMixed` の往復（分ける → 混合 → 分ける で並びが保たれ、番号が 1 からになる）。draft 以外の切り替えは 409。
- サーバー: 混合の大会で選手を足すと `A-混合-1-n` の通し番号。性別を変えても order が変わらない。二巡目生成が男女通しの得点順。並べ替えがコート×巡目の全員で通る。
- 大会ファイルの取り込み・コピーで `settings.mixed` が写る。
- 画面の表示テスト（既存の desk-match / desk-players / app.js のテストがあれば）: 順番列が無い、混合の組の見出し。

## 7. 申し送り

- ヘルプの画像は No. 列が写ったまま（文言だけ更新）。
- 既存の大会で No. が消えるので、初めて開いたとき「番号が無くなった」と見える。ヘルプの一節で説明する。
- 混合大会を旧バージョンのサーバーで開くと order の `混合` が読めず「未分類」扱いになる（本番は同時に更新するので実運用では起きない）。
