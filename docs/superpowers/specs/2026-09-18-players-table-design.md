# 選手タブの表形式化（絞り込み・並べ替え） 設計書

作成日: 2026-09-18

## 目的

運営画面（`admin.html`）の選手タブを、カード形式の一覧から**表形式**に変え、
コート・性別・巡目・新人・技未入力・名前で絞り込み、番号・名前・得点で
並べ替えできるようにする。スマホ幅（375px）でも表形式のままとし、
横スクロールを許して全列を 1 行で表示する。

## 現状と問題

- `admin-players.js` の `renderList` がカード（`<button class="row">`）を並べる。
  1 行が 2 段（`order ＋ 名前` と `技 / 技 / 技`）で、1 画面に並ぶ人数が少ない
- 絞り込みはコートのチップ（`Admin.renderCourtChips`）だけ。性別・巡目・新人・
  技未入力での絞り込みや名前検索ができない
- 並び順は `Courts.compareOrder`（巡目 → コート → 性別 → 番号）固定で、
  名前順・得点順に並べ替えられない
- `A-男子-1-1` という `order` 文字列（コート-性別-巡目-番号）がそのまま表示され、
  各要素を目で分解する必要がある

## 方針

- `order` 文字列は**データとしてはそのまま**残す（サーバーの採番・二巡目生成・
  採点画面の並びが解析している）。表示だけを 4 列（巡・コート・性・No）に分解する
- フィルタとソートは**純粋関数**として `courts.js` に置き、`test.html` で固定する。
  `admin-players.js` は状態の保持と DOM 生成だけを担う
- サーバー（`server/index.js`）、採点画面（`app.js`）、進行タブ（`admin-round.js`）、
  選手の追加・編集・一括登録シート、`⋯` メニューは変更しない

## 画面構成（選手タブ）

```
選手 66名                                    ⋯
[全コート][A][B]  [男女][男子][女子]  [全巡][1巡][2巡]  [新人]  [技未入力]
[🔍 名前で検索                    ]
┌──┬────┬──┬────┬──────────┬────┬────┬────┬──┬────┐
│巡│ｺｰﾄ│性│No ▲│名前       │技① │技② │技③ │新│得点│
├──┼────┼──┼────┼──────────┼────┼────┼────┼──┼────┤
│1 │A   │男│ 1  │ジュリアーノ熊代│破図味│夢想返し│響き返し│ │ 66│
│1 │A   │男│ 2  │箕輪 憲人   │水月 │陽中陰│夢想返し│ │ 47│
```

### 表

- 列：巡・コート・性・No・名前・技①・技②・技③・新・得点（10 列）。
  技①②③の呼び名は編集シートの「①②③」に合わせる
- 1 行 1 段。セルは折り返さない（`white-space: nowrap`）。表全体が幅を超えたら
  表の枠（`.players-table-wrap`）だけ横スクロールする（採点表 `.score-table-wrap` と同じ方式）
- **名前列は左に固定**（`position: sticky; left: 0`。採点表の固定列と同じ手法）。
  横スクロール中も誰の行か分かるようにする。巡〜No の 4 列は幅が小さいので固定しない
- 空の技は「—」。技が 3 つとも空なら技①に「未入力」を薄い色で出し、技②③は「—」
- 新人は「新」列に「●」、それ以外は空
- 得点は `p.score || 0` を表示（現状と同じ）。色は既存の `--score-color`
- 行の高さは 44px 以上（タップ目標）
- 行タップで既存の編集シート（`openEditSheet`）を開く。右下の「＋」も現状どおり
- 大会に選手が 0 名なら現状の案内文（「選手がまだいません。…」）。
  選手はいるが条件に合う行が 0 件なら「条件に合う選手がいません。」

### 絞り込み部品

- 1 段目：コートのチップ（既存 `Admin.renderCourtChips`）。「全コート」「A コート」「B コート」「未分類」
- 2 段目：性別「男女／男子／女子」、巡目「全巡／1巡／2巡…」、トグル「新人」「技未入力」。
  横に並べ、375px に収まらなければその段だけ横スクロール（`.court-chips` と同じ `overflow-x: auto`）
- 3 段目：名前検索の入力欄（`type="search"`、placeholder「名前で検索」）
- チップは高さ 32px の小型版（`.chip-sm`）。選択中は既存 `.court-chip.on` と同じ配色
- 巡目チップの候補は、選手の `Courts.roundOf` の一意な値を昇順に並べたもの
  （二巡目未生成なら「全巡／1巡」だけ）

## 絞り込み・並べ替えの振る舞い

### フィルタ状態

```js
{ court: '', sex: '', round: 0, newFace: false, noTech: false, query: '' }
```

- `court`：'' で全コート。`Courts.courtOf(p)` と一致
- `sex`：'' | '男子' | '女子'。`order` の第 2 セグメントで判定（`isFemale` は持たない前提。
  `orderKey(p).sex` を使う）
- `round`：0 で全巡。`Courts.roundOf(p)` と一致
- `newFace`：true なら `p.isNewFace` が真の行だけ
- `noTech`：true なら `tech1/tech2/tech3` がすべて空の行だけ
- `query`：名前の部分一致。`normalizeName` で正規化してから比較する
  （前後の空白を除き、全角・半角スペースを取り除く。大文字小文字は区別しない）。
  「箕輪 憲人」を「箕輪憲人」でも当てる
- すべて AND

### ソート状態

```js
{ key: 'order' | 'name' | 'score', dir: 'asc' | 'desc' }
```

- 既定は `{ key: 'order', dir: 'asc' }`（= 現状の `Courts.compareOrder`）
- 見出し No・名前・得点のタップで切り替える。別の列なら昇順に切替、同じ列なら昇⇄降。
  ソート中の見出しに ▲（昇順）▼（降順）を付ける
- 巡・コート・性・技・新の見出しはソート対象外（巡・コート・性はフィルタ軸）
- `name` は `String.prototype.localeCompare(other, 'ja')`。`score` は `Number(p.score) || 0` で数値比較
- 同値のときは `Courts.compareOrder` で並べて安定させる
- 得点ソートは表示中の行全体を並べる（巡目をまたぐ）。巡目ごとの順位は
  巡目フィルタと組み合わせる（専用の切り替えは作らない）

### 状態の寿命

- 大会を切り替えたら既定に戻す（現状の `courtOwner` と同じ仕組みで、
  `ctx.eventId` が変わったら初期化）
- ページ再読込でも既定に戻す（`localStorage` に保存しない）
- 選手の追加・編集・削除後の再描画（`render` の再呼び出し）ではフィルタ・ソートを維持する
- 絞り込み中のコートの選手が全員いなくなったら全コートに戻す（既存ルールを維持）。
  巡目についても同様に、絞り込み中の巡目の選手がいなくなったら全巡に戻す

## 実装の置き場

| ファイル | 変更 |
|---|---|
| `courts.js` | 純粋関数を追加：`Courts.normalizeName(s)`、`Courts.hasNoTech(p)`、`Courts.sexOf(p)`（'男子' \| '女子' \| ''）、`Courts.applyFilter(players, filter)`、`Courts.sortBy(players, sort)`（元配列を変更せず新しい配列を返す）、`Courts.defaultFilter()`、`Courts.defaultSort()` |
| `admin-players.js` | `currentCourt` を `filter` / `sort` の 2 オブジェクトに置き換え。`renderList` を `<table>` 生成に書き換え（`buildRow` → `buildTr`）。チップ・検索欄・見出しタップの配線。`openMenu` / `openAddSheet` / `openEditSheet` / 一括登録は触らない |
| `admin.js` | 汎用の `Admin.renderChips(container, items, current, onChange)` を追加（`items` は `{ value, label }` の配列）。`renderCourtChips` はこれを使う薄いラッパーにし、進行タブから見た挙動（クラス名・`dataset.court`・文言）は変えない |
| `admin.css` | `.players-filters`（2 段目の帯）、`.chip-sm`（32px チップ）、`.players-search`、`.players-table-wrap`（横スクロール枠）、`.players-table`（nowrap・名前列 sticky・見出しの ▲▼・行 44px）を追加。既存の `.row` 系は進行タブが使うので残す |
| `help.html` | 選手タブの説明と `help/img/admin_players.png` を表形式に差し替え。「絞り込み」「並べ替え」の短い段落を追加 |

## テスト

### 自動（`test.html` に追加）

- `normalizeName`：前後空白、全角スペース、半角スペースを除き、大文字小文字を同一視
- `hasNoTech`：3 つとも空（未定義・空文字）→ true。1 つでも入っていれば false
- `sexOf`：`A-女子-1-3` → '女子'、解析不能 → ''
- `applyFilter`：コート／性別／巡目／新人／技未入力／名前の各条件が単独で効くこと、
  複数条件が AND になること、既定のフィルタで全件が返ること
- `sortBy`：`order` 昇順が `compareOrder` と一致、降順が逆順。`name` が日本語順。
  `score` が数値順（"10" と "9" の文字列比較にならない）。同点時は `order` 順で安定。
  元配列を変更しない
- 既存の `Courts.*` テストが壊れないこと

### 手動（ブラウザのモバイル表示 375px）

1. 表が横スクロールし、名前列が左に固定されて追従する
2. 見出し No／名前／得点 のタップで ▲▼ が切り替わり、順序が変わる
3. 巡目フィルタ「1巡」＋得点降順で 1 巡目の順位が出る。「全巡」＋得点降順で全体順位
4. 名前検索「箕輪憲人」で「箕輪 憲人」が出る
5. 「技未入力」で技が 3 つとも空の選手だけになる
6. 選手を編集・追加してもフィルタとソートが維持される
7. 大会を切り替えると既定（全コート・男女・全巡・No 昇順）に戻る
8. 進行タブのコートチップが従来どおり動く
9. PC 幅でも崩れない

## 変えないもの

- `order` 文字列の形式と、サーバー側の採番・二巡目生成
- 採点画面（`index.html` / `app.js`）の選手一覧
- 進行タブ（`admin-round.js`）のカード一覧
- 選手の追加・編集・一括登録シート、CSV インポート、`⋯` メニュー
