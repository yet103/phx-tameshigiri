## 章立て（この順で `help.html` に書く）

目次（各章へのページ内リンク）→ 0. 全体の流れ（図）→ 1〜5 の章。

### 0. 全体の流れ（流れ図）

大会前日〜当日〜終了後の流れを1枚の SVG で。ノード: 「大会を作る」→「選手を登録」→「コート端末で採点（一巡目）」→「二巡目を生成・技を入力」→「採点（二巡目）」→「結果の確認」→「発表・共有」。各ノードに「どの画面で」（運営画面／採点画面／発表モード）を小さく添える。端末の役割（運営者のスマホ／コートのタブレット／会場の大画面／参加者のスマホ）も図に入れる。

### 1. 大会の作成

- 運営画面（`admin.html`）を開く → 大会タブ「＋ 新規大会」 → 大会名・日付・会場 → 作成。画像: `admin_events.png`, `admin_new_event.png`
- 選手の登録は3通り: (a) 「＋」で1人ずつ（名前・コート・性別・新人・技①②③）、(b) 「⋯」→「複数人をまとめて登録」（1行1人の貼り付け。コート・性別・新人は共通指定。技は後で）、(c) 「⋯」→「CSV インポート」（列: 名前,コート,性別,技①,技②,技③,新人。順番は自動採番。従来の9列形式も可）。画像: `admin_players.png`, `admin_players_menu.png`, `admin_bulk.png`, `admin_player_form.png`
- 技の選び方（①②③ をタップ → シートで検索 → 選ぶ。打てない太刀は「—」）。画像: `admin_tech_sheet.png`
- 順番（コート-性別-巡目-番号）は自動で付く。コートは A・B のように「-」を含まない名前。

### 2. 採点の進行（A・B の2コートの例）

- 端末の役割分担を図で: 運営者のスマホ（運営画面）、A コートのタブレット、B コートのタブレット。各タブレットは採点画面でコートを選んで使う（URL にコートが付く。進行タブの「採点画面へ」から開くと絞り込み中のコートで開く）。
- 採点画面の見方（画像 `scoring_tablet.png` に番号を振って説明）: ①大会・コートの選択、②選手名の帯（コートのバッジ・順番・名前）、③タイマー、④採点表（技名をタップして行を選ぶ。太刀セルは 未→成功→失敗→未）、⑤形成功／失敗（選択中の行に効く）、⑥補正点（技ごと・全体）と備考、⑦確定（得点が青になる。編集すると解除）、⑧下部の選手一覧（タップで切替、開閉できる）。
- 二巡目: 一巡目が終わったら運営画面の進行タブで「二巡目を生成」→ 一覧に二巡目の行が出る → 技を入れる（「一巡目と同じ技をコピー」も可）→ 各コートの採点画面に二巡目の選手が並ぶ。画像: `admin_round.png`, `admin_round_court_b.png`
- 注意: 採点は端末に一時保存して送信するので、通信が切れても続けられる（上部の「保存済み／未保存 n 件」の見方）。他の端末が書いた確定・備考は、選手を切り替えたときに取り込まれる。

### 3. 得点の集計

- 得点の式: 太刀の配点合計＋技ごとの補正点＋全体補正点。技の配点は「技術リスト編集」で変えられる（変えたら採点し直す必要がある旨）。
- 部門: 一般男子／一般女子／新人（新人は男女の部にも入る）。同点は同順位。
- 確認の場所: 運営画面の結果タブ（「最新に更新」）、順位表示ページ（`ranking.html`。HTML ダウンロード可）、採点画面の「CSV エクスポート」「HTML 保存」。画像: `admin_results.png`, `ranking_page.png`

### 4. サイト掲載（共有・発表）

- 結果タブ「共有リンクをコピー」→ 参加者に配る URL（`share.html#トークン`）。誰でも閲覧専用で順位を見られる。画像: `share_mobile.png`
- 結果タブ「発表モードで開く」→ 会場の大画面で。「掲示」は部門ごとに表示、「発表」は下位から1人ずつ開く。全画面ボタン。画像: `present_board.png`, `present_reveal.png`
- 流れ図: 結果タブ → 共有リンク（参加者のスマホ）／発表モード（大画面）。

### 5. 困ったとき

- 「技が未入力です」→ 進行タブで技を入れる。
- 「内訳を復元できません」→ 技の数が変わった選手。採点し直す。
- 「未保存 n 件」→ 通信を確認。端末を閉じずに待つ。再試行ボタン。
- 技が見つからない → 技術リスト編集で確認。
- ヘルプの入口（全ページ上部の「ヘルプ」、運営画面の「⋯」）。

## 書き方の規約

- 見出しは短く、本文は1文ずつ。操作は「画面 → ボタン → 結果」の順で書く。
- 画像は `<figure>` に `<img loading="lazy" alt="…">` と `<figcaption>`。番号を振って説明する画像は、画像の上に CSS で番号バッジを重ねず、キャプションの箇条書きで「①…」と対応させる（画像を差し替えても崩れないため）。
- 流れ図はインライン SVG。色は theme 変数（`fill="var(--accent)"` など）。文字は 14px 以上。スマホでは横スクロールせず縮む（`viewBox` と `width:100%`）。
- 目次は `<nav>` に章へのリンク。各章に `id`。
- 印刷用に `@media print` で目次のリンク色と背景を整える（帯は黒のまま印刷されないよう `print-color-adjust` は指定しない）。
- 事実は必ず実装（`app.js` / `admin-*.js` / `server/index.js`）に合わせる。ボタンの文言は画面の文言と一字一句同じにする。
