# ダッシュボードの閲覧専用: 採点の面を「見るだけで触れる」にする

日付: 2026-10-10
ユーザー要望: 「閲覧専用の際にも、選手一覧を選択するとその選手のスコア（採点はできない）が表示されたり、スクロールバーを操作したり、個々の画面の倍率を変えたりはしたい（採点行為だけ禁止）。閲覧専用の時は形成功や失敗・確定済み・次の選手などの操作ボタンを非表示。開始停止リセットも非表示」。決定: 別の選手を見ているときは**採点席が次の選手に移ったら自動で戻る**（手動は「▶ 戻る」）。順位の面の盾は外す。

## 1. 決めたこと

- 閲覧専用（dashboard の view モード）で、**採点の面（scoring.html の iframe）の盾（.pane-shield）をやめ**、採点画面に **閲覧モード**（`viewOnly`）を持たせる。閲覧モードの採点画面は「採点行為だけ禁止」で、それ以外は触れる。
- **運営の面（desk.html#match）は盾のまま**（運営操作の誤押し防止。スクロールは通る）。**順位の面（ranking.html）は盾を外す**（内訳・ベスト4 の切り替えは無害）。
- **面ごとの倍率**: 面の見出しに「−　75%　＋」。面ごとに保存。上の帯の「縮小」は一括設定で、面ごとの指定があればそれを優先。「▦ 面」のメニューに「倍率をそろえる」（面ごとの指定を消す）。

## 2. 採点画面の閲覧モード（app.js）

`viewOnly`（真偽値。既定 false）。ダッシュボードから `ScoringApp.setViewOnly(flag)`（同一オリジン。iframe の `contentWindow` から呼ぶ）で切り替える。面として開かれた直後は、親の `body.dash-edit` の有無から初期値を決める（親が読めなければ false）。

閲覧モード（`viewOnly === true`）のとき:

| 項目 | 挙動 |
|---|---|
| 形成功・失敗・確定・確定して次へ・前の選手・次の選手 | **非表示**（`body.view-only` の CSS で `.action-bar` のボタンを隠す。合計の表示は残す） |
| タイマーの開始・停止・リセット | **非表示**。残り時間の表示は残り、採点席の live のタイマーを映す（今の追いかけと同じ） |
| ○×△ のセル・補正点・全体補正・備考・文例・「計算し直して保存」 | 押せない・入力できない（`score-frozen` と同じ見た目＋`pointer-events: none`） |
| 大会・コートの切り替え（eventSelect / courtSelect） | 無効（disabled） |
| 一覧のドラッグ（⋮⋮） | 非表示 |
| 選手一覧の行 | **押せる**。押した選手の採点内容を表示する（「見るだけの選択」。持ち主にならない・配信を送らない・`gridEdited` にしない） |
| 他のコートの一覧の行 | 押しても何もしない（面はコートごとなので） |
| 書き込み | **一切しない**。`Api.updatePlayer` 系・`publishLive`・並べ替えの入口に `viewOnly` の番を置く |

### 見るだけの選択と「戻る」

- 一覧で別の選手を押すと **追いかけを止めて**その選手を出す（`viewPinnedId` にその id）。
- 画面上部（選手の帯の上）に **帯「採点中: 衛藤豊　04:12　▶ 戻る」** を出す（採点席の選手名と残り時間。残り時間は live のタイマーで毎秒進む）。「▶ 戻る」で `viewPinnedId` を消し、追いかけに戻る。
- **自動で戻る**: `refreshFromServer` のたびに live の選手を見て、**live の選手が「見るだけの選択をした時点の live の選手」から変わったら**（＝採点席が次の選手に移った）`viewPinnedId` を消して追いかけに戻る。live が空（待機中）になったときも戻る。
- 見ている選手が live の選手と同じなら帯は出さない。
- 規則は純粋関数 `Courts.viewFollowDecision({ pinnedId, pinnedLiveId, liveId })` → `'follow' | 'pinned'` に切り出し、test.html で固定する。
  - `pinnedId` が無い → follow
  - `liveId` が `pinnedLiveId` と違う（次の選手に移った、または空） → follow
  - それ以外 → pinned

### 操作可能に切り替えたとき

`setViewOnly(false)` で帯と制限を外す。`viewPinnedId` は消す（追いかけに戻る）。持ち主の扱いは今のまま（面で操作した時から持ち主、閲覧専用に戻すと外れる）。

### 通常の採点画面（iframe でない）

`viewOnly` は常に false。挙動は変えない。

## 3. ダッシュボード（dashboard.js / dashboard.css）

- 盾は `desk` の面だけに付ける（view モードのとき）。`court` と `rank` の面には付けない。
- `applyMode()` で各 `court` の面の iframe に `contentWindow.ScoringApp.setViewOnly(mode === 'view')` を呼ぶ（読み込み前なら `load` 後に呼ぶ）。見出しの印「閲覧専用」は今のまま。
- **面ごとの倍率**: 見出しの × の左に「−」「75%」「＋」（50〜125%、5 刻み）。`localStorage` の `tmg_dashboard_zoom_pane`（JSON `{ "court:A": 60, "rank": 100 }`）。`applyZoom()` は面ごとに `paneZoom[key] || zoom` を使う。「▦ 面」のメニューに「倍率をそろえる（全部を上の縮小に）」。面の倍率の表示は面の見出しに出す。
- 上限を 125% まで広げるのは面ごとの指定だけ（上の帯のつまみは今まで通り 50〜100）。

## 4. テスト

- `Courts.viewFollowDecision` の 4 つの場合。
- dashboard.js の倍率の決定（`paneZoomFor(key, paneZoom, zoom)` を純粋関数に）と保存の形。
- ブラウザ: 閲覧専用のまま一覧の選手を押して内訳が見える、○× や補正点を押しても変わらない、サーバーへの書き込みが無い（ネットワーク）、「▶ 戻る」、採点席が次の選手に移ると自動で戻る、面ごとの倍率が効いて再読み込み後も残る、操作可能に切り替えると今までどおり採点できる。

## 5. ヘルプ・資料

- help.html のダッシュボードの節: 閲覧専用でできること（選手を見る・スクロール・倍率）、できないこと、帯の「▶ 戻る」と自動復帰。
- 実況席向け資料（docs/memo/2026-10-07-commentary-guide.html）の「1. 画面の全体」の上の帯の説明と、「2.」の一覧の説明を更新（写真は撮り直さない。文言で補う）。

## 6. 変えないもの

通常の採点画面の挙動、運営の面の盾、観戦ダッシュボード（watch.html）、配信の持ち主の規則。
